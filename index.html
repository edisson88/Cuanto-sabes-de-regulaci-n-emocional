¿Quién quiere ser millonario?

Este simulador permite elegir preguntas libremente, acumular respuestas correctas y usar ayudas conceptuales antes de responder. Cuando una respuesta sea incorrecta, el sistema la registrará como incorrecta y mostrará la retroalimentación del porqué.

Cómo funciona: eliges una pregunta, seleccionas una opción y esa selección se toma como respuesta definitiva.
Ayuda conceptual: puedes revisar una pista antes de responder con el botón de ayuda.
Meta: completar las 20 preguntas acumulando la mayor cantidad de respuestas correctas.
